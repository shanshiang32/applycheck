# 20岗人工复核

双击review-20.html即可离线打开。无需安装依赖、访问官网或启动云端任务。

本页内嵌20个不同岗位的采集原文、URL、时间和正文哈希；没有内嵌程序的条件答案或判断结论。用于独立填写人工标签，但复核者此前已看过部分程序结果，因此不称为严格盲测。

## 第一轮先做3岗

1. 填写复核者姓名或代号（可选），从第1岗开始。
2. 阅读左侧采集快照，只填写当前岗位明确的硬条件。不要引用“相关职位”中的内容。
3. 学历填最低要求；在校只按原文在读/在校要求；月份和出勤填数字；多条硬下界取最严格值。优先/加分条件写入备注，不作为硬下界。
4. 未明确的字段选择或填写“未明确”，不能猜月份或当作没有要求。已知字段在对应文本框粘贴支持该值的原句，程序会验证引用确实出现在快照正文。
5. 毕业年月范围例：2026-09~2027-08；明确的届别下界例：>=2028。单独写某届但没有年月范围的情况填“未明确”并备注。
6. 根据固定画像独立判断，写一句依据，再点“确认本岗已复核”。标注不完整时不会计为完成。
7. 做完前3岗后点“导出复核结果”，得到applycheck-human-review.json，上传聊天。其余岗位可以分批完成。

画像固定为本次用户提供的硕士、2025年已毕业、非在校、实习6个月/每周5天。不能将此前的2027在读测试画像作为用户事实。

本地草稿尽力自动保存；不同浏览器、清理缓存或移动文件可能无法恢复。定期导出JSON；下次打开后可用“导入上次结果”续做。修改已确认的字段会将本岗退回草稿，需再次确认。

## 评分口径

只对completed=true且通过引用/格式/来源校验的记录计分。五类字段包括学历、在校要求、最短实习月数、最低出勤和明确毕业范围/下界。硬条件同字段取最严格下界；专业、技能、偏好项等不在该分母内。程序结果固定为0.1.13的20岗汇总，不随人工标签改动。

score.mjs可计算已完成标签与程序字段的一致性并列出差异。未完成不计入分母，不能以0条完成人工复核声称100%准确率。已知字段一致数、含未知的总槽位一致数与岗位结论分别记录；全为不匹配的样本无法衡量对可匹配岗位的误拒率。

```powershell
node .\evaluation\manual-review\score.mjs --input "下载文件的完整路径\applycheck-human-review.json"
```

页面计时仅为页面打开时间，包含停顿，不是严格有效人工工作时间，也不是人机效率比较。后续如需效率对比，应另设计同任务的独立计时实验。

build.mjs可由evaluation/reviewed-20/results.json重新生成页面；check-core.mjs与check-ui.mjs分别检查核心验证及DOM模拟交互。未进行真实浏览器截图验收，首次打开可结合用户实际页面反馈检查布局。
