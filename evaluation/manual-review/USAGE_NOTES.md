# 实际平台用量记录

请从Lexmount控制台的项目用量或任务记录获取实际数字；不根据采集elapsed_ms反推计费，也不预填费用。usage-log-template.json为待填写模板。

建议记录范围：本项目开始日至当前日期，注明控制台使用的时区、计费单位和统计时间。若包含其他项目，不能把总账单全部算入ApplyCheck。

至少保留：项目浏览器总用量（若可取得）、实际费用和币种、成功/失败任务数、对应统计起止时间、统计截图或导出文件名。若控制台不能提供任务级费用，填项目总费用并注明范围；不能猜每岗成本。

成功岗位详情、重采、入口探测、失败发现和错误配置尝试都是不同用途，费用统计应尽量包含排查和失败，不能仅记录成功样本。不同岗位样本仍为20，重复读取不增加该分母。

当前可靠事实：20份有效不同岗位原文、5份隔日重复详情、字节和美团各一次进入手机登录阶段的成功证据。历史失败任务清单仍需与平台记录对账，不能据此写全流程成功率。

之后可提供控制台项目用量截图或导出，与人工复核分开提交即可。
