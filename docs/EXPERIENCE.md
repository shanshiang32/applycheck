# 交互体验发布记录

公开入口：https://shanshiang32.github.io/applycheck/try/

无需登录和密钥，浏览器本地运行，共用 `lib/rules.js` 规则引擎。默认虚构案例，可切换历史 20 岗记录；不实时读取招聘站点、不执行登录或投递。支持画像预设、自定义条件、状态筛选、逐项原文和 JSON 下载。修改画像后需点击重新核验。

验证：72 项 Node 离线测试；浏览器核验默认虚构案例 1/1/1，未知画像 0/0/3，历史已毕业硕士画像 0/17/3；切换数据、筛选、展开证据正常，390px 移动端无横向溢出。

体验页是比赛介绍用的独立静态功能，不改变比赛提交网站，也不替作者发送邮件或授权展示。
