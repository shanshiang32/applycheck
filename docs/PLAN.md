## 作品竞争力

1. 不只搜索岗位：进入官网详情，核验明确条件及入口阶段。
2. 每条判断可追溯：来源、观察时间、条件原文和运行记录可对应。
3. 不确定性清楚：不匹配、匹配部分明确条件、信息不足各自呈现。
4. 变化有前后文：条件更改和页面失效与临时访问失败分开。
5. 有真实评估：与人工核验和仅列表汇总的基线对比。
